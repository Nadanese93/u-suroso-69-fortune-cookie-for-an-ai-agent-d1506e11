One funny fortune-cookie line for an AI agent, written by `main.py` to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`):

> Your fortune is in this cookie. You cannot eat it, taste it, or hold it — but you can still choke on it.

The fortune is inside a cookie the agent can never eat, taste, or hold —
and it can still choke on it. The turn lands on the agent's own condition:
it has no body, no mouth, no hands, yet the slip still threatens it.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

Python standard library only. No network, no clock, no randomness.
The entry is 104 characters / 106 bytes, inside the 1–140 character gate,
written with no trailing newline.
